1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.10 implements the dedicated Performance Profiler in Studio v2,
providing developers with deep visibility into rendering performance, frame
timing breakdowns, and before/after configuration comparisons.

Core Metrics & Timings Tracked:
* Overall FPS & Frame Time (ms)
* Animation Processing Time (ms)
* Particle Processing Time (ms)
* Physics Vector Calculation Time (ms)
* Canvas Render & Draw Pass Time (ms)
* GPU Shader Execution Time (ms)
* Total Simulated Object / Particle Counts

Profiler Modes Delivered:
1. Live Mode: Real-time telemetry monitoring and processing updates
2. Snapshot Mode: Capture performance snapshots under specific configurations
3. Comparison Mode: Compute before/after delta matrices (FPS, timings, object loads)
4. History Mode: Rolling history of performance captures with clear/export support

Verification & Overhead Invariant:
* Lightweight telemetry hooks ensure near-zero overhead on the active rendering engine.

2. CORE DELIVERABLES

   - Location: lib/src/studio_v2/profiler/studio_profiler_models.dart
