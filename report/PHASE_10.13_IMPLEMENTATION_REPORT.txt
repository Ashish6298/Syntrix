1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.13 implements the unified, multi-format Export & Import System in
Studio v2, providing deterministic, reproducible artifact generation across all
major Studio subsystems.

Supported Export Entities:
* Configuration (Visual inspector parameter states)
* Preset (Complete presets library and single preset bundles)
* Scene (Composite multi-layer scenes)
* Generated Code (Production-ready Flutter widgets)
* Diagnostics (Subsystem health sweeps and error logs)
* Performance Report (Telemetry metrics and snapshot comparisons)

Supported Target Formats:
* JSON (structured data schema, automated tooling)
* Dart (compile-ready code, public APIs)
* Markdown / PlainText (human-readable documentation and ASCII wireframes)

Determinism & Reproducibility Guarantee:
* Exports produce standardized, reproducible payloads without non-deterministic
  leakage or runtime inconsistencies.
