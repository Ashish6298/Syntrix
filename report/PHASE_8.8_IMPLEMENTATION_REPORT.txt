Phase 8.8 implements the AI Dependency & Compatibility Advisor inside flutter_package_studio_core,

1. Dependency Finding Model & Vocabulary:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/dependencies/dependency_models.dart`.
   - Structured `DependencyFinding` subclasses `CodeReviewFinding` from Phase 8.3, conforming
     strictly to the established schema:
     `Severity`, `Category`, `File`, `Location`, `Problem`, `Explanation`, `Recommendation`, `Confidence`,
     extended with:
     `DependencyName`, `CurrentConstraint`, `ArtifactType`, `Certainty`, and `AffectedPackages`.
   - Reuses Phase 8.3 `CodeReviewSeverity` (`critical`, `high`, `medium`, `low`, `informational`)
     and `CodeReviewConfidence` (`high`, `medium`, `low`).
   - `DependencyArtifactType` enum captures all requested concern types:
     `versionConflict`, `duplication`, `deprecatedPackage`, `sdkConstraintViolation`,
     `crossPackageInconsistency`, `upgradeRisk`, `generalDependency`.
   - `CompatibilityCertainty` enum captures the three-way certainty classification:
     `locallyVerified`, `inferred`, `externallyResearched`.
   - `DependencyAnalysisScope`: `wholeProject`, `package`.
   - `DependencyAnalysisRequest` & `DependencyAnalysisResult`.

2. Grounded Dependency Advisor Engine & Deterministic Pre-Flight:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/dependencies/dependency_advisor_engine.dart`.
   - Manifest Gathering: Non-evaluating, safe extraction of pubspec.yaml and pubspec.lock files across
     all discovered monorepo packages.
   - Deterministic Conflict & Duplication Detection:
     - Identifies conflicting version constraint ranges (e.g. `meta ^1.11.0` vs `meta ^2.0.0`) deterministically.
     - Identifies Dart SDK environment constraint mismatches across monorepo packages.
     - Identifies known deprecated packages (e.g. `pedantic`, `intl_translation`).
     - Tags deterministic findings with `CompatibilityCertainty.locallyVerified`.
   - AI Reasoning Layer:
     - Evaluates upgrade risks, semver gap implications, and transitive compatibility.
     - Tags reasoning with `CompatibilityCertainty.inferred` or `CompatibilityCertainty.externallyResearched`.
   - Strict Read-Only Safety: Zero file writes, mutations, or automatic pubspec version bumps.
   - Sensitive-File Exclusion: Reuses Phase 8.2 context layer filters to exclude `.env`,
     `credentials.json`, and secret tokens from outbound prompts.
   - Fail-Closed AI Handling: Safe error containment when provider is faulted or times out.

3. Pure Dual-Format Renderer & CLI Integration:
   - Built `DependencyAdvisorRenderer` in `packages/flutter_package_studio_core/lib/src/ai/dependencies/dependency_advisor_renderer.dart`.
   - Added `DependencyCommand` in `packages/flutter_package_studio_cli/lib/src/commands/dependency_command.dart`
     accessible via `fps deps` (alias `fps dependencies`) with `--target`, `--scope`, `--package`, `--dir`,
     `--budget`, `--output`, `--write`, `--check-duplicates`, and `--json`.
