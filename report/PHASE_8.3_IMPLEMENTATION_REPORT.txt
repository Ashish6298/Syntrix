1. OBJECTIVE & ARCHITECTURAL OVERVIEW
────────────────────────────────────────────────────────────────────────────────
Phase 8.3 delivers the AI Code Analysis & Review Engine for Flutter Package Studio,
building strictly on top of Phase 8.1 (AI Assistant Core Foundation) and Phase 8.2
(Project Context & Codebase Intelligence):

1. Structured Finding Domain Models:
   - Built under `packages/flutter_package_studio_core/lib/src/ai/review/code_review_models.dart`.
   - Strictly conforms to the required finding schema:
     * Severity: `critical`, `high`, `medium`, `low`, `informational` (aligned with platform standards).
     * Category: `bugRisk`, `codeSmell`, `architecture`, `apiUsage`, `errorHandling`,
       `maintainability`, `duplication`, `complexity`, `asyncBehavior`, `unsafePattern`, `flutterLifecycle`.
     * File: Relative path of the inspected file.
     * Location: Precise line/range (e.g. `L16`) or symbol identifier.
     * Problem: Concise summary of the defect or anti-pattern.
     * Explanation: Detailed root cause and context rationale.
     * Recommendation: Concrete, actionable remediation instructions.
     * Confidence: Honest signal (`high`, `medium`, `low`), avoiding artificial constant certainty.

2. Four Distinct Review Modes in CodeReviewEngine:
   - Built under `packages/flutter_package_studio_core/lib/src/ai/review/code_review_engine.dart`.
   - `singleFile`: Inspects a single file path in detail.
   - `packageLevel`: Iterates package files via Phase 8.2 context layer, aggregates findings,
     and deduplicates cross-file duplication findings.
   - `changeFocused`: Scopes findings strictly to modified files / diff hunks, using surrounding files
     only as context.
   - `architectureFocused`: Coarser-grained pass reporting architectural, API, and complexity
     findings while strictly suppressing line-level nitpicks.

3. Strict Read-Only Safety Invariant:
   - This phase ONLY recommends.
   - Zero file writes, zero patch applications, zero formatter invocations, zero subprocess execution.
   - Produces pure JSON and Markdown reports through `CodeReviewRenderer`.

4. Fail-Closed Error Containment:
   - Unavailable or faulted AI providers return structured `CodeReviewResult.failure` without crashing
     or emitting fabricated empty results.

5. CLI Integration:
   - Registered `fps review` in `packages/flutter_package_studio_cli/lib/src/commands/review_command.dart`.
