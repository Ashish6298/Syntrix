1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.2 establishes the central Unified Studio Workspace where developers
can interact with every major package capability through a clean 4-quadrant layout:

```text
┌──────────────────────────────────────────────┐
│                Studio Toolbar                │
├──────────────┬───────────────────────────────┤
│              │                               │
│ Navigation   │        Live Preview           │
│              │                               │
│              │                               │
├──────────────┼───────────────────────────────┤
│ Inspector    │ Configuration / Output        │
│              │                               │
└──────────────┴───────────────────────────────┘
```

Core Capabilities Coordinated in the Workspace:
* Loader selection (all existing cosmic/package loaders)
* Theme selection (deep_space, solar_flare, nebula_storm, etc.)
* Animation configuration (speed, intensity, scale)
* Particle configuration (count, size, opacity)
* Physics configuration (gravity, velocity)
* Rendering & shader toggle controls
* Live performance inspection (FPS, frame time ms, active particle count)
* Bottom-right console tabs (Configuration, CodeGen, Diagnostics, Metrics, Export)
* Production-ready Flutter code generation conforming to visual controls
