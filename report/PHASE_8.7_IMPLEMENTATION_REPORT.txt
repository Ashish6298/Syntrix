1. OBJECTIVE & ARCHITECTURAL OVERVIEW
────────────────────────────────────────────────────────────────────────────────
Phase 8.7 implements the AI Documentation Assistant inside flutter_package_studio_core,
building strictly on top of the already-completed Phases 8.1 (AI Assistant Core Foundation),
8.2 (Project Context & Codebase Intelligence), 8.3 (AI Code Analysis & Review Engine),
8.4 (AI Test Generation & Test Intelligence), 8.5 (AI Debugging & Failure Diagnosis),
and 8.6 (AI Architecture Advisor):

1. Documentation Finding Model & Vocabulary:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/documentation/documentation_models.dart`.
   - Structured `DocumentationMismatchFinding` subclasses `CodeReviewFinding` from Phase 8.3,
     conforming strictly to the schema:
     `Severity`, `Category`, `File`, `Location`, `Problem`, `Explanation`, `Recommendation`, `Confidence`,
     extended with:
     `ArtifactType`, `ImplementedReality`, and `DocumentedClaim`.
   - Reuses Phase 8.3 `CodeReviewSeverity` (`critical`, `high`, `medium`, `low`, `informational`)
     and `CodeReviewConfidence` (`high`, `medium`, `low`).
   - `DocumentationType` enum captures all requested artifact types:
     `apiDoc`, `readmeSection`, `cliDoc`, `architectureExplanation`, `usageExample`, `troubleshootingDoc`,
     `releaseDoc`, `migrationNote`, `developerGuide`.
   - `DocumentationArtifactType` enum captures discrepancy classes:
     `cliOption`, `apiMember`, `configKey`, `exceptionType`, `generalDoc`.
   - `DocumentationGenerationRequest` & `DocumentationGenerationResult` (with `sourceEvidenceManifest` and `evidenceGapNotice`).
   - `DocumentationConsistencyRequest` & `DocumentationConsistencyResult`.

2. Grounded Documentation Assistant Engine:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/documentation/documentation_assistant_engine.dart`.
   - Source Evidence Grounding: Gathers real project files and symbols via Phase 8.2 context discovery
     (`ProjectContextEngine.assembleContext()` and `discoverProject()`).
   - Anti-Hallucination Gate: When requested to document an unverified class, method, or feature
     where no evidence exists in the discovered workspace, the engine strictly declines to invent
     fictitious content, sets `evidenceGapNotice`, and emits 0 AI completion calls.
   - Documentation Inconsistency Detection: Scans implemented CLI argument parsers (`addOption`/`addFlag`)
     and source code method signatures, comparing them against documented claims in markdown docs
     to surface structured `DocumentationMismatchFinding` items with concrete recommendations.
   - Terminology Preservation: Preserves exact class, method, option, and command identifiers without alteration.
   - Strict Read-Only Safety: Zero file writes, mutations, or automatic file updates.
   - Sensitive-File Exclusion: Reuses Phase 8.2 filters to exclude `.env`, `credentials.json`,
     and secret files from prompts.
   - Fail-Closed AI Handling: Safe error containment when provider is faulted or times out.

3. Pure Dual-Format Renderer & CLI Integration:
   - Built `DocumentationAssistantRenderer` in `packages/flutter_package_studio_core/lib/src/ai/documentation/documentation_assistant_renderer.dart`.
   - Added `DocumentationCommand` in `packages/flutter_package_studio_cli/lib/src/commands/documentation_command.dart`
     accessible via `fps doc` (alias `fps documentation`) with `--target`, `--type`, `--package`, `--dir`,
     `--budget`, `--output`, `--write`, `--check-consistency`, and `--json`.
