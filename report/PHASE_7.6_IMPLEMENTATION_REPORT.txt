PHASE 7.6 OBJECTIVE & NON-EXECUTION GOVERNING CONSTRAINT
--------------------------------------------------------
  Implement Phase 7.6 — Plugin Dependency & Compatibility Manager for Flutter Package Studio, responsible for analyzing discovered plugin collections, building a dependency graph, categorizing ecosystem incompatibilities, and computing a deterministic topological initialization ordering.
  Governing Rule: "This phase ONLY ever answers questions about a plugin ecosystem — it NEVER activates, initializes, or executes a single plugin."

================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. PLUGIN DEPENDENCY RESOLVER (`lib/src/plugin/dependency/plugin_dependency_resolver.dart`)
   - Non-Execution Graph Analyzer: Builds dependency graph across `PluginManifest` objects using Phase 7.5 `PluginDependency` value objects. Zero plugin code execution or instantiation.
   - Categorized Problem Diagnostics:
     * `missingDependency`: Plugin A depends on missing Plugin B ID.
     * `versionConflict`: Malformed version constraint or range mismatch.
     * `circularDependency`: Cycles detected in graph (extracts exact cycle path string, e.g. `A -> B -> C -> A`).
     * `unsupportedApiVersion`: Reuses Phase 7.1/7.5 `PluginContractValidator.supportedApiVersions`.
     * `incompatiblePluginVersion`: Plugin B present, but version fails Plugin A's version constraint.
     * `dependencyOrderingImpossible`: Surfaced when topological sort cannot resolve all nodes.
   - Deterministic Topological Sort: Uses Kahn's algorithm with `PluginId` alphanumeric sorting as a secondary tie-breaker, guaranteeing byte-identical ordering regardless of input iteration order.
   - Blocked Result Guarantee: Any blocked resolution (`isCompatible == false`) NEVER carries a partial or best-effort initialization order list.

2. CLI INTEGRATION (`fps template plugin-deps-resolve <dir1> [dir2...]`)
   - Added `fps template plugin-deps-resolve` subcommand under `TemplateCatalogCommand` supporting directory root arguments, formatted human-readable output, and `--json` output.
