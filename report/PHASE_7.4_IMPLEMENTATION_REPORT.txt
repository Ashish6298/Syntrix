PHASE 7.4 OBJECTIVE & NON-EXECUTION GUARANTEE
---------------------------------------------
  Implement Phase 7.4 — Plugin Discovery Engine for Flutter Package Studio, responsible for scanning untrusted filesystem directory roots to locate plugin manifest files (`plugin.json`), parsing raw text JSON, and delegating validation to Phase 7.1's `PluginContractValidator`.
  Governing Rule: "Discovery ONLY ever reads and parses declared metadata — it NEVER imports, loads, links, or executes anything found on disk."

================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. PLUGIN DISCOVERY ENGINE (`lib/src/plugin/discovery/plugin_discovery_engine.dart`)
   - Non-Execution Traverser: Scans directory roots, inspecting only `plugin.json` files as raw text. Completely ignores source files (`.dart`), compiled objects (`.so`, `.dll`), and native binaries.
   - Defensive Filesystem Handling:
     * Oversized manifest check (> 512 KB) fails closed fail-safe.
     * Corrupted / Non-UTF-8 manifest bytes caught and reported as `invalid`.
     * Symlink policy: Explicitly does NOT follow symlinks (`followLinks: false`), flagging symlinks as invalid to prevent path traversal attacks.
     * Unreadable / permission-denied directories reported fail-closed without crashing the engine process.
   - Deterministic Result Aggregator: Sorts entries canonically by `PluginId` (or directory path), ensuring identical byte-for-byte results regardless of underlying OS directory listing order.
   - Inert Data Guarantee: Discovery results remain pure value objects (`DiscoveryResult`, `DiscoveredPluginEntry`). Registration into Phase 7.3's `PluginRegistry` is NOT performed automatically.

2. CLI INTEGRATION (`fps template plugin-discover <dir1> [dir2...]`)
   - Added `fps template plugin-discover` subcommand under `TemplateCatalogCommand` supporting directory root arguments, formatted human-readable output, and `--json` structured output.
