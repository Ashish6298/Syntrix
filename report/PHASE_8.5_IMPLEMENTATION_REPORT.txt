1. OBJECTIVE & ARCHITECTURAL OVERVIEW
────────────────────────────────────────────────────────────────────────────────
Phase 8.5 implements the AI Debugging & Failure Diagnosis engine in
flutter_package_studio_core, building strictly on top of Phase 8.1 (AI Assistant Core),
Phase 8.2 (Project Context & Codebase Intelligence), Phase 8.3 (AI Code Analysis &
Review Engine), and Phase 8.4 (AI Test Generation & Test Intelligence):

1. Structured Diagnosis Domain Models:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/diagnosis/failure_diagnosis_models.dart`.
   - `CauseCertainty` enum: `confirmed`, `probable`, `possible`.
   - `DiagnosedCause`: Description, `CauseCertainty`, and rationale.
   - `EvidenceType`: `stackTrace`, `testFailure`, `analyzerOutput`, `cliError`,
     `buildError`, `historicalReport`, `generalLog`.
   - `DiagnosisEvidenceItem` & `FailureEvidenceBundle`: Pluggable evidence intake.
   - `VerificationStep`: Concrete step number, action command, and expected outcome.
   - `FailureDiagnosis`: All 7 required fields (`problem`, `likelyCauses`, `citedEvidence`,
     `affectedComponents`, `recommendedFix`, `risk`, `verificationSteps`).
   - `DiagnosisRequest` & `DiagnosisResult`.

2. Failure Diagnosis Engine & Evidence Pipeline:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/diagnosis/failure_diagnosis_engine.dart`.
   - Scopes failure evidence and inspects relevant source code via Phase 8.2 context layer.
   - Narrows affected components (packages and file paths).
   - Ingests and cites prior phase verification reports (`report/phase_8_x_verification_report.txt`).
   - Enforces tiered cause synthesis, preventing cause certainty from collapsing into free text.
   - Emits structured remediation recommendations and human verification steps.

3. Pure Dual-Format Renderer & CLI Command:
   - Built `FailureDiagnosisRenderer` in `packages/flutter_package_studio_core/lib/src/ai/diagnosis/failure_diagnosis_renderer.dart`.
   - Built and registered `DebugCommand` in `packages/flutter_package_studio_cli/lib/src/commands/debug_command.dart`
     accessible via `fps debug` with `--error`, `--stack-trace`, `--file`, `--package`, `--dir`, `--budget`, `--output`, `--write`, `--json`.
