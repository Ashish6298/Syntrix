PHASE 4.7 OBJECTIVE
-------------------
  Introduce a production-grade, deterministic, plan-first Code Coverage Analysis
  subsystem under `flutter_package_studio_core` that consumes structured test results
  and LCOV-compatible coverage data (`lcov.info`) to calculate line coverage, evaluate
  threshold rules, and generate aggregate coverage reports without executing tests or
  mutating the original package.
