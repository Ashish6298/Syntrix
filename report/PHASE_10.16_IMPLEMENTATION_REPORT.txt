1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.16 implements the Cross-Platform Environment Center in Studio v2,
allowing developers to inspect platform-specific package behavior, verified
renderer backends, shader capabilities, diagnostics support, and known platform
limitations across all 6 major Flutter target platforms.

Target Platforms Evaluated:
* Android (Impeller Vulkan / OpenGLES)
* iOS (Impeller Metal)
* Web (CanvasKit Wasm / WebGL2)
* Windows (ANGLE DirectX 11 / Skia)
* macOS (Impeller Metal)
* Linux (Skia OpenGL / Wayland / X11)

Environment Display Model:
```text
┌────────────────────────┐
│ Environment            │
├────────────────────────┤
│ Android      ✓         │
│ iOS          ✓         │
│ Web          ✓         │
│ Windows      ✓         │
│ macOS        ✓         │
│ Linux        ✓         │
├────────────────────────┤
│ Host: Windows          │
└────────────────────────┘
```

Factual Integrity Invariant:
* Studio rigorously distinguishes between verified capabilities and unavailable
  runtime parameters without inventing or approximating runtime values.
