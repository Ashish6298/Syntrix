PHASE 5.5 OBJECTIVE
-------------------
  Introduce a production-grade, deterministic, plan-first Release Artifact Manifest
  subsystem under `flutter_package_studio_core` that creates a canonical machine-readable
  and human-readable manifest describing the complete release artifact set produced or expected
  for a package release, including SHA-256 cryptographic checksums, file sizes, relative paths,
  provenance, and integrity verification without publishing or modifying source package files.

================================================================================
  SUMMARY OF IMPLEMENTATION

   - ArtifactChecksum, ArtifactProvenance, ReleaseArtifactEntry, ManifestOptions, ReleaseArtifactManifestPlan & ReleaseArtifactManifestResult:
     Immutable domain models holding artifact metadata, cryptographic checksums, provenance, options, plans,

   - ReleaseArtifactManifestGenerator: Core service compiling manifest entries, computing real SHA-256 digests, and verifying manifest integrity.
