ARCHITECTURE DECISIONS
----------------------
  - TemplateCatalog is a mutable in-memory index returning immutable query results.
  - TemplateDiscoveryService caches merged catalog; invalidate() forces rebuild.
  - No network, no disk I/O -- 100% deterministic and side-effect free.
  - BuiltinCatalogProvider uses stable indexedAt = 2025-01-01 UTC for test determinism.
  - TemplateCatalogCommand extends FpsCommand for CommandRegistry compatibility.
  - TemplateCommand preserved as typedef alias for backward compatibility.
  - CatalogException added to the centralized exception hierarchy.
  - Strict separation: discovery is orthogonal to registry/resolver/generator.
