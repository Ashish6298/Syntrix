PHASE 5.6 OBJECTIVE
-------------------
  Introduce a production-grade, deterministic, plan-first Release Security & Secret Audit
  subsystem under `flutter_package_studio_core` that performs a comprehensive security audit
  of package source files, generated build artifacts, and release manifest data to detect
  accidentally exposed secrets, API tokens, private keys, `.env` files, and sensitive path
  references without publishing, network calls, or secret leakage.

================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. RELEASE SECURITY & SECRET AUDIT SUBSYSTEM (`src/release/security/`)
   - SecurityFindingSeverity, SecurityFindingType, SecurityFinding, SecurityScanTarget, SecurityAuditOptions, ReleaseSecurityAuditPlan & ReleaseSecurityAuditResult:
     Immutable domain models holding scan targets, finding categories, severity levels, options, plans,
     and results rendering Markdown report output and JSON dictionaries with automatic secret redaction.
   - ReleaseSecurityAuditor: Core auditor service inspecting files, pattern matching for secret leaks, redacting matches, and building audit reports.
