1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 9.5 establishes the controlled human approval and release governance
subsystem for Flutter Package Studio (`Syntrix`).

It replaces uncoordinated developer direct publishing with a structured,
auditable, multi-tier release governance pipeline:
  Developer -> Build -> Security Audit -> Verification -> Reviewer Approval ->
  Release Manager Approval -> Publish.

Key Architectural Principle:
The system maintains a strict non-bypassable distinction between
**Technical Verification** (e.g. security audits, pub.dev validation, release
verification pipeline) and **Organizational Approval** (human votes and sign-offs).
Human approval cannot bypass failing technical gates unless a verified
administrative override is executed.

2. KEY ARCHITECTURAL DELIVERABLES
--------------------------------------------------------------------------------

A. Approval Domain Models
-------------------------
- File: `lib/src/enterprise/approval/enterprise_approval_models.dart`
- Key Models:
  * `ApprovalStatus`: Pending, Approved, Rejected, Cancelled, Expired.
  * `ApprovalVoteAction`: Approve, Reject, RequestChanges, Override.
  * `ApprovalVote`: Voter ID, display name, voter enterprise role, action,
    timestamp, and comments.
  * `ApprovalPolicy`: Configurable reviewer counts, release manager counts,
    pre-approval verification gates, and validity duration.
  * `ApprovalRequest`: Candidate package name, target channel, version,
    requester identity, satisfied technical gates, votes, and expiration.

B. Central Enterprise Approval Engine
-------------------------------------
- File: `lib/src/enterprise/approval/enterprise_approval_engine.dart`
- Key Features:
  * Manages request lifecycle (Create, Vote, Reject, Cancel, Override, Expire).
  * Enforces required reviewer and release manager approval thresholds.
  * Persistent storage in `.fps/approval/approval_history.jsonl`.
  * `isReleaseAuthorized()` gate checking both technical verification satisfaction
    and organizational human approval.

C. Dual-Format Approval Renderer
--------------------------------
- File: `lib/src/enterprise/approval/enterprise_approval_renderer.dart`
- Output: Pure deterministic JSON & Markdown release approval reports with
  vote histories, gate statuses, and cancellation/override reasons.

D. Barrel Exports & Core Integration
------------------------------------
- Exported in `lib/src/enterprise/enterprise.dart` and `flutter_package_studio_core.dart`.
