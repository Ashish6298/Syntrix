PHASE 4.10 OBJECTIVE
--------------------
  Introduce a production-grade, deterministic, plan-first Regression Testing
  subsystem under `flutter_package_studio_core` that defines regression suites, discovers
  previously verified package capabilities, constructs regression scenarios from existing test
  profiles and compatibility dimensions, executes only through the existing controlled Test
  Runner abstraction when explicitly requested, compares current execution evidence against defined
