1. OBJECTIVE & ARCHITECTURAL OVERVIEW
────────────────────────────────────────────────────────────────────────────────
Phase 8.4 implements the AI Test Generation & Test Intelligence Engine in
flutter_package_studio_core, building strictly on top of Phase 8.1 (AI Assistant Core),
Phase 8.2 (Project Context & Codebase Intelligence), and Phase 8.3 (AI Code Analysis
& Review Engine):

1. Structured Coverage Gap & Test Intelligence Domain Models:
   - Built under `packages/flutter_package_studio_core/lib/src/ai/testing/test_intelligence_models.dart`.
   - `TestGapSeverity` (`critical`, `high`, `medium`, `low`).
   - `TestGapCategory` (`boundaryCondition`, `failureScenario`, `securityScenario`,
     `regressionRisk`, `cliEdgeCase`, `invalidInput`, `generalMissingCase`).
   - `MissingTestCase`: Immutable structured record containing id, title, category,
     severity, rationale, testConditions, and expectedOutcome.
   - `TargetCoverageGapReport`: Groups missing test cases by target (e.g. Class / Command).
   - `TestTrackingState` (`existing`, `suggested`, `executed`, `passed`, `failed`):
     Lifecycle state machine strictly prohibiting invalid transitions (e.g. passed without executed).
   - `TrackedTestCase`: Inert, queryable tracking snapshot representing the test status
     across packages.
   - `ProposedTestFile`: Encapsulates generated candidate Dart test snippets isolated
     from the active test suite.

2. Accurate Test Pairing & Coverage Intelligence Engine:
   - Built under `packages/flutter_package_studio_core/lib/src/ai/testing/test_intelligence_engine.dart`.
   - Leverages Phase 8.2 context layer and content introspection to accurately match
     implementation files with their test files (even with atypical naming conventions).
   - Detects regression risks (modified code or zero test pairings).
   - Detects CLI edge cases (missing required flag/option handling).

3. Safety & Proposal Isolation Invariants:
   - Test proposals are written strictly to isolated locations (e.g. `report/proposed_tests/`
     with `.proposed` extensions).
   - NEVER mutates or writes into the real `test/` directory.
   - Working tree byte-comparison confirms zero side-effects.
   - Approval Gate: Suggested tests are excluded from `existingCoverage` until approved.
   - Sensitive File Protection: Zero `.env` or credential leakage into prompts/proposals.

4. Dual-Format Renderer & CLI:
   - Built `TestIntelligenceRenderer` (`src/ai/testing/test_intelligence_renderer.dart`)
     for schema-valid JSON and clean Markdown reports.
   - Registered `AiTestCommand` in `packages/flutter_package_studio_cli/lib/src/commands/ai_test_command.dart`
     accessible via `fps test` with `--package`, `--file`, `--dir`, `--proposals`, `--budget`, `--write`, `--json`.
