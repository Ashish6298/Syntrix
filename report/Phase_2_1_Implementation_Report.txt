2. ARCHITECTURE & ADVANCED TEMPLATE CAPABILITIES
--------------------------------------------------------------------------------
- Semantic Versioning (`TemplateSemVer`):
  Immutable model parsing semver strings (`major.minor.patch[-prerelease]`) with constraint evaluation (`>=1.0.0 <2.0.0`, `^1.0.0`).
- Template Dependency Graph Solver (`TemplateDependency` & `TemplateDependencySolver`):
  Declarative dependency declarations with topological sorting and cycle detection (`detectCircularDependencies()`).
- Template Capabilities & Compatibility (`TemplateCapabilities` & `TemplateCompatibility`):
  Metadata-driven capabilities (`package`, `application`, `plugin`, `federated_plugin`, `cli`, `library`) and SDK/platform bounds.
- Composition & Conflict Resolution (`TemplateCompositionEngine` & `ResolvedTemplate`):
  Composes base templates with feature extensions and resolves file collisions using explicit override strategies (`fail`, `override`, `skip`) while tracking provenance (`fileProvenance`).
- Template Orchestration Layer (`TemplateResolver`):
  Dedicated resolution layer looking up, resolving dependencies, and composing templates prior to generation planning.
- Registry Upgrade (`TemplateRegistry`):
  Upgraded registry supporting composite keying (`id@version`), SemVer matching, capability filtering, and tag search.
