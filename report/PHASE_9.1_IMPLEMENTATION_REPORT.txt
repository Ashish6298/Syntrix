1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 9.1 establishes the centralized, declarative, and composable Enterprise
Configuration & Policy Engine for Flutter Package Studio.

Instead of hardcoding rules across disparate subsystems, Phase 9.1 introduces
a hierarchical policy architecture:
  Organization Policy -> Project Policy -> Package Policy -> Environment Policy

All policies are declarative, composable, and fail-closed under strict enforcement.

--------------------------------------------------------------------------------
2. KEY ARCHITECTURAL DELIVERABLES
--------------------------------------------------------------------------------

A. Enterprise Policy Domain Models
----------------------------------
- File: `lib/src/enterprise/policy/enterprise_policy_models.dart`
- Key Models:
  * `EnterprisePolicyDocument`: Master declarative policy definition.
  * `EnterprisePolicyProfile`: Presets (Standard, Strict, Financial, Healthcare,
    Government, OpenSource, Custom).
  * `PolicyEnforcementMode`: Strict (blocks on violation), Permissive (warns),
    AuditOnly (records silently).
  * `ReleasePolicyConfig`: Mandatory verification gates, pub.dev validation,
    security audit requirements, Git tag rules, changelog enforcement.
  * `SecurityPolicyConfig`: Blocked file patterns (.env*, *.key, *.pem),
    secret redaction rules, critical/high vulnerability thresholds.
  * `AiUsagePolicyConfig`: Local vs. external AI allowances, allowed capabilities,
    command sandboxing, prompt sanitization.
  * `DependencyPolicyConfig`: Allowed / blocked packages, license restrictions.
  * `NamingAndVersioningPolicyConfig`: Semver enforcement, package naming regexes.
  * `OperationPolicyConfig`: Allowed and blocked operations.
  * `PolicyEvaluationResult` & `PolicyEvaluationFinding`: Structured outcome models.

B. Central Enterprise Policy Engine
-----------------------------------
- File: `lib/src/enterprise/policy/enterprise_policy_engine.dart`
- Key Features:
  * Hierarchical resolution: Searches `.fps/policy.json`, `.fps/policy.yaml`,
    `enterprise_policy.json`, and package-specific `.fps_policy.json`.
  * Composable policy inheritance: `orgPolicy.composeWith(childPolicy)`.
  * Multi-dimensional policy evaluation: Security, Release, AI Usage,
    Dependencies, Operations.
  * Strict gate blocking logic.

C. Pure Dual-Format Renderer
----------------------------
- File: `lib/src/enterprise/policy/enterprise_policy_renderer.dart`
- Output: Deterministic JSON & Markdown reports with executive summaries and
  findings breakdown.

D. Barrel Exports & Core Integration
------------------------------------
- File: `lib/src/enterprise/enterprise.dart`
- Exported in `flutter_package_studio_core.dart`.
