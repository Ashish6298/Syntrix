   - `ConfigurationProperty`: Declares key, type (`string`, `number`, `boolean`, `map`, `list`), `isRequired`, and `isSecret` flag.
   - `ConfigurationSchema`: Holds set of properties, rejecting duplicate property keys fail-closed.
   - `PluginDependency`: Value object for plugin dependencies, rejecting empty strings or self-referential dependencies.
   - `SecurityRequirements`: Immutable value object declaring required permissions and sandbox requirements.
   - `PluginManifest`: Extended in place with optional fields `entryPoint`, `dependencies`, `configSchema`, and `securityRequirements`.

2. PLUGIN CONFIGURATION SYSTEM (`lib/src/plugin/configuration/`)
   - `SecretValue`: Wrapper type overriding `toString()` and `toJson()` to return `[REDACTED]`.
   - `RuntimeConfiguration`: Holds installation-specific configuration values map, redacting secret keys in stringification.
   - `PluginConfigurationValidator`: Assesses runtime configuration against declared schemas with multi-violation attributed reporting and secret redaction in error messages.

3. CLI INTEGRATION (`fps template plugin-config-validate`)
