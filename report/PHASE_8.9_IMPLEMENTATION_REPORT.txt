1. OBJECTIVE & ARCHITECTURAL OVERVIEW
────────────────────────────────────────────────────────────────────────────────
Phase 8.9 implements the AI Security & Privacy Advisor inside flutter_package_studio_core,
building strictly on top of the already-completed Phases 8.1 through 8.8 and integrating
directly with existing Milestone 5 and 6 deterministic release-security and secret auditing
infrastructure:

1. Security Finding Model & Vocabulary:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/security/security_models.dart`.
   - Structured `SecurityFindingItem` subclasses `CodeReviewFinding` from Phase 8.3, conforming
     strictly to the established schema:
     `Severity`, `Category`, `File`, `Location`, `Problem`, `Explanation`, `Recommendation`, `Confidence`,
     extended with:
     `Priority`, `SecurityCategory`, `Evidence`, `Impact`, and `VerificationProcedure`.
   - Reuses Phase 8.3 `CodeReviewSeverity` through a clean 1:1 mapping with `SecurityPriority`:
     `critical` -> `CodeReviewSeverity.critical`
     `high` -> `CodeReviewSeverity.high`
     `medium` -> `CodeReviewSeverity.medium`
     `low` -> `CodeReviewSeverity.low`
     `informational` -> `CodeReviewSeverity.informational`.
   - `SecurityFindingCategory` enum captures all requested concern types:
     `fileExposure`, `authenticationHandling`, `credentialHandling`, `dangerousConfiguration`,
     `dependencyRisk`, `releaseArtifactRisk`, `manifestRisk`, `secretExposure`.
   - `SecurityAnalysisScope`: `wholeProject`, `package`.
   - `SecurityAnalysisRequest` & `SecurityAnalysisResult`.

2. Grounded Security Advisor Engine & Deterministic Correlation:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/security/security_advisor_engine.dart`.
   - Central Redaction Authority (`SecretRedactor`):
     A newly extracted, standalone universal secret redaction utility under
     `packages/flutter_package_studio_core/lib/src/ai/security/secret_redactor.dart`.
     Guarantees zero raw secret values appear in AI prompts, findings, evidence, JSON, or Markdown.
     All existing tests in Phases 8.2, 8.7, and 8.8 were re-run and pass 100% without modification.
   - Deterministic Ingestion:
     Consumes deterministic security audit outputs, secret scanner findings, and sensitive-file detections.
   - Dependency Security Correlation:
     Reuses Phase 8.8 `DependencyFinding` findings to correlate deprecated and unmaintained package risks.
   - AI Reasoning Layer:
     Generates plain-language risk explanations, impact assessments, and human verification procedures
     grounded strictly in redacted evidence.
   - Strict Read-Only Safety Invariant:
     Zero file mutations, zero automated credential rotations, and zero file deletions.
   - Fail-Closed AI Handling:
     Safe error containment when provider is faulted or times out.

3. Pure Dual-Format Renderer & CLI Integration:
   - Built `SecurityAdvisorRenderer` in `packages/flutter_package_studio_core/lib/src/ai/security/security_advisor_renderer.dart`
     with a non-optional final redaction pass immediately before returning.
   - Added `SecurityCommand` in `packages/flutter_package_studio_cli/lib/src/commands/security_command.dart`
     accessible via `fps security` (alias `fps ai-security`) with `--target`, `--scope`, `--package`,
     `--dir`, `--min-priority`, `--budget`, `--output`, `--write`, and `--json`.
