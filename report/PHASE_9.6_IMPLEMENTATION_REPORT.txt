1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 9.6 establishes the centralized Enterprise Dependency Governance Engine
for Flutter Package Studio (`Syntrix`). It enables organizations to define,
enforce, and audit dependency constraints across packages without duplicating
underlying dependency discovery.

--------------------------------------------------------------------------------
2. KEY ARCHITECTURAL DELIVERABLES
--------------------------------------------------------------------------------

A. Dependency Governance Domain Models
--------------------------------------
- File: `lib/src/enterprise/dependency/enterprise_dependency_models.dart`
- Key Models:
  * `DependencyGovernanceStatus`: Approved, Restricted, Blocked, Unclassified,
    Vulnerable, Outdated, LicenseViolation.
  * `DependencyType`: Direct, Dev, Transitive, Override.
  * `DependencyGovernanceFinding`: Package name, version, dependency type, status,
    rationale, license, advisory ID, recommendation, and blocking flag.
  * `EnterpriseDependencyPolicy`: Configurable approved packages list, restricted
    packages list, blocked packages list, allowed/blocked licenses (GPL vs MIT/Apache),
    and path/git release restrictions.
  * `DependencyGovernanceResult`: Comprehensive audit outcome with counts and summary.

B. Central Enterprise Dependency Governance Engine
--------------------------------------------------
- File: `lib/src/enterprise/dependency/enterprise_dependency_engine.dart`
- Key Features:
  * Analyzes direct and dev dependencies from `pubspec.yaml`.
  * Blocks prohibited/blocked packages and strict allowlist violations.
  * Detects copyleft license violations (e.g., GPL-3.0, AGPL-3.0 vs. MIT/BSD/Apache).
  * Traps active security advisories / known vulnerabilities.
  * Detects and blocks local path/git dependency leaks in release packages.

C. Pure Dual-Format Dependency Renderer
---------------------------------------
- File: `lib/src/enterprise/dependency/enterprise_dependency_renderer.dart`
- Output: Pure deterministic JSON & Markdown dependency governance audit reports.

D. Barrel Exports & Core Integration
------------------------------------
- Exported in `lib/src/enterprise/enterprise.dart` and `flutter_package_studio_core.dart`.
