PHASE 5.10 OBJECTIVE
--------------------
  Introduce a production-grade, deterministic, plan-first Release Channel Manager
  subsystem under `flutter_package_studio_core` that models release channels (`stable`, `beta`, `dev`, `canary`),
  evaluates release promotion eligibility, enforces version/stability policies across channels, prevents invalid channel promotions or downgrades,
  and generates deterministic machine-readable JSON and human-readable Markdown promotion reports without modifying package files or performing unauthorized network calls.
