1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
The objective of Phase 9.13 is to harden enterprise release workflows and
operational executions against unexpected system crashes, network drops, and
service interruptions while maintaining strict idempotency guarantees.

Core Architectural Principle:
"An interrupted enterprise operation must be recoverable without accidentally
executing the same destructive operation twice."

Guaranteed Capabilities:
* Stage Checkpointing (atomic, step-by-step state recording on disk)
* Interrupted Workflow Detection (recovers in-flight jobs upon reboot)
* Idempotency Guard (prevents re-tagging or re-publishing packages already completed)
* Safe Rollback & Compensation (compensates completed stages and audits action)
* Resilient State Handling (gracefully quarantines corrupted JSON state files)
* Full Tamper-Evident Audit Trail Integration

2. CORE DELIVERABLES
--------------------------------------------------------------------------------
1. Reliability Domain Models
   - Location: lib/src/enterprise/reliability/enterprise_reliability_models.dart
   - Components:
     * CheckpointStatus (active, completed, failed, interrupted, rolledBack)
     * OperationCheckpoint (checkpoint ID, stage ID, destructive flag, completion state, state payload)
     * PersistentExecutionState (full on-disk state representation of active/interrupted workflows)
     * RecoveryOperationResult (structured outcome of resume or rollback operations)

2. Enterprise Reliability & Recovery Engine
   - Location: lib/src/enterprise/reliability/enterprise_reliability_engine.dart
   - Capabilities:
     * Atomic on-disk state persistence in `.fps/recovery/<workflow_id>.state.json` via temp-file rename.
     * `initializeState()`: registers workflow execution baseline.
     * `recordCheckpoint()`: checkpoints stage outcomes incrementally.
     * `markInterrupted()`: flags incomplete executions as interrupted.
     * `resumeInterruptedWorkflow()`: inspects completed stages and skips completed destructive operations (Idempotency Guard).
     * `rollbackWorkflow()`: compensates completed stages and marks state as rolled back.
     * Corrupted state quarantine and fault-tolerant parsing.

3. Reliability Dual-Format Renderer
   - Location: lib/src/enterprise/reliability/enterprise_reliability_renderer.dart
   - Formats:
     * Structured JSON recovery summaries.
     * Formatted Markdown reports detailing actions taken and idempotency guard logs.

4. Barrel Export & Subsystem Integration
   - Exported through: lib/src/enterprise/enterprise.dart & lib/flutter_package_studio_core.dart
