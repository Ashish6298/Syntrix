1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.7 turns Studio v2 into a visual scene composition environment,
enabling developers to build composite multi-layer animation scenes
using package components.

Composite Scene Architecture Implemented:
```text
Scene
├── Background Layer        (e.g. Deep Space, Solar Flare)
│
├── Primary Loader Layer     (e.g. Galaxy Orbit, Infinite Universe)
│
├── Particle Layer           (e.g. Cosmic Dust, Starlight Particles)
│
├── Effect Layer             (e.g. Nebula Glow, Shimmer, Ionization)
│
└── Interaction Layer        (e.g. Gesture Enabled, Drag/Touch Overlay)
```

Capabilities Delivered:
* Dynamic Layer Management: Add, remove, reorder Z-index, and toggle visibility/opacity.
* Independent Layer Configuration: Each layer carries its own isolated component configuration.
* Scene Persistence: Save and restore scenes across Studio workspace sessions.
* Composition Code Generation: Generates production-ready Flutter `Stack` composition widgets.
* Composition Invariant: Operates purely as a composition layer; does NOT rewrite core rendering algorithms.

2. CORE DELIVERABLES
--------------------------------------------------------------------------------
1. Scene Builder Domain Models
   - Location: lib/src/studio_v2/scene/studio_scene_models.dart
   - Components:
     * SceneLayerType (background, primaryLoader, particleLayer, effectLayer, interactionOverlay, custom)
     * SceneComponentLayer (layerId, name, layerType, componentReference, zIndex, opacity, isVisible)
     * VisualSceneDescriptor (composite scene model with width, height, layers, and timestamps)

2. Studio Scene Builder Engine
   - Location: lib/src/studio_v2/scene/studio_scene_engine.dart
   - Capabilities:
     * Pre-configured default 5-layer composite scene.
     * `addLayer()`, `removeLayer()`, `reorderLayer()`, `configureLayer()`.
     * Automatic Z-index sorting on layer mutations.
     * `saveScene()` and `restoreScene()` for workspace scene persistence.
     * `generateSceneFlutterCode()` producing Flutter `Stack` widgets with `Opacity` and `SceneComponent` wrappers.

3. Studio Scene Multi-Format Renderer
   - Location: lib/src/studio_v2/scene/studio_scene_renderer.dart
   - Formats:
     * ASCII Scene Layer Tree wireframe (matching Milestone 10.7 specifications).
     * Markdown Layer Hierarchy table and code blocks.
     * Structured JSON scene descriptor export.

4. Barrel Export & Monorepo Integration
   - Exported through: lib/src/studio_v2/studio_v2.dart & lib/flutter_package_studio_core.dart
