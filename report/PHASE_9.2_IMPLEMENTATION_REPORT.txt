1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 9.2 introduces an identity-aware operation control framework for Flutter
Package Studio (`Syntrix`). It enables the system to reliably ascertain "who is
performing an operation" (human developer, release manager, administrator, or
automated CI service account) without tightly coupling the platform to any
single authentication provider.

--------------------------------------------------------------------------------
2. KEY ARCHITECTURAL DELIVERABLES
--------------------------------------------------------------------------------

A. Enterprise Identity Domain Models
------------------------------------
- File: `lib/src/enterprise/identity/enterprise_identity_models.dart`
- Key Models:
  * `EnterpriseIdentity`: Subject definition with id, displayName, email,
    organizationId, assigned roles, direct permissions, claims, and metadata.
  * `EnterpriseRole`: Standardized enterprise roles:
    - Administrator
    - Release Manager
    - Developer
    - Reviewer
    - Security Auditor
    - Read Only
    - Custom Role
  * `IdentityType`: User, ServiceAccount, ApiToken, Anonymous.
  * `AuthenticationStatus`: Authenticated, Unauthenticated, Expired, Revoked, Anonymous.
  * `EnterpriseSession`: Session lifecycle token, issuance/expiration timestamps,
    and provider reference.

B. Pluggable Identity Provider Abstraction
------------------------------------------
- File: `lib/src/enterprise/identity/enterprise_identity_provider.dart`
- Interface: `EnterpriseIdentityProvider` for pluggable authentication providers
  (Local, OAuth2/OIDC, SAML, API Token, Mock).
- Built-in Implementation: `MockEnterpriseIdentityProvider` for deterministic unit
  testing, offline operation, and CI automation.

C. Central Identity Manager & Session Cache
-------------------------------------------
- File: `lib/src/enterprise/identity/enterprise_identity_manager.dart`
- Key Features:
  * Manages provider registry.
  * Resolves identity from environment service tokens (`FPS_ENTERPRISE_TOKEN`),
    active memory session, persistent cache (`.fps/session.json`), or anonymous fallback.
  * Handles login, session persistence, session validation, and logout.

D. Dual-Format Identity Renderer
--------------------------------
- File: `lib/src/enterprise/identity/enterprise_identity_renderer.dart`
- Output: Structured JSON & Markdown user profiles detailing roles, permissions,
  and active session health.

E. Barrel Exports
-----------------
- Exported via `lib/src/enterprise/enterprise.dart` and `flutter_package_studio_core.dart`.
