1. OBJECTIVE & ARCHITECTURAL OVERVIEW
────────────────────────────────────────────────────────────────────────────────
Phase 8.6 implements the AI Architecture Advisor inside flutter_package_studio_core,
building strictly on top of the already-completed Phases 8.1 (AI Assistant Core Foundation),
8.2 (Project Context & Codebase Intelligence), 8.3 (AI Code Analysis & Review Engine),
8.4 (AI Test Generation & Test Intelligence), and 8.5 (AI Debugging & Failure Diagnosis):

1. Architecture Finding Model & Vocabulary:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/architecture/architecture_models.dart`.
   - Structured `ArchitectureFinding` conforms strictly to the schema:
     `Component`, `Issue`, `Recommendation`, `Reason`, `Severity`, `Confidence`, and `Category`.
   - Reuses Phase 8.3 `CodeReviewSeverity` (`critical`, `high`, `medium`, `low`, `informational`)
     and `CodeReviewConfidence` (`high`, `medium`, `low`).
   - `ArchitectureCategory` enum captures key architectural defect classes:
     `circularDependency`, `layeringViolation`, `misplacedResponsibility`, `duplicateFunctionality`,
     `excessiveCoupling`, `apiInconsistency`, `poorAbstractionBoundary`, `ruleViolation`, `generalArchitecture`.
   - `ArchitectureScanScope`: `wholeProject`, `package`, `subsystem`.
   - `MonorepoStructuralModel`: Topology model of monorepo packages, inter-package dependencies,
     and detected dependency cycles.

2. Architecture Advisor Engine & Structural Reasoning:
   - Built in `packages/flutter_package_studio_core/lib/src/ai/architecture/architecture_advisor_engine.dart`.
   - Structural Modeling: Discovers full project snapshot via Phase 8.2 context discovery,
     constructing an inter-package dependency graph without hardcoded topology.
   - Cycle Detection: Executes Tarjan / DFS cycle detection to detect real circular dependency cycles.
   - Deterministic Heuristics: Accurately identifies CLI commands containing domain business logic
     (e.g. package generation in CLI) and duplicate code blocks replicated across modules.
   - Scoped vs. Whole-Project Scans: Filters findings to target package when scoped to a package.
   - Strict Read-Only Safety: Zero file writes, moves, import edits, or project mutations.
   - Sensitive-File Exclusion: Excludes sensitive files (`.env`, credentials) and non-architectural
     configuration files (`.gitignore`) from AI prompts.
   - Fail-Closed AI Handling: Safe error containment when provider is faulted or times out.

3. Pure Dual-Format Renderer & CLI Integration:
   - Built `ArchitectureAdvisorRenderer` in `packages/flutter_package_studio_core/lib/src/ai/architecture/architecture_advisor_renderer.dart`.
   - Added `ArchitectureCommand` in `packages/flutter_package_studio_cli/lib/src/commands/architecture_command.dart`
     accessible via `fps architecture` with `--package`, `--subsystem`, `--dir`, `--budget`, `--output`, `--write`, and `--json`.
