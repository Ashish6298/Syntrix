1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.14 implements the Loader Comparison Laboratory in Studio v2, providing
a side-by-side benchmarking and evaluation environment where developers can
compare loaders prior to choosing one for their Flutter application.

Evaluation & Benchmarking Dimensions:
* Visual Behavior & Animation Flow
* Configuration Parameter Mappings
* FPS Performance & Render Pass Durations (ms)
* Particle Count & Particle Pool Loads
* Physics Integrators & Gravitation Status
* GPU Fragment Shaders & Post-Processing Effects
* Feature Compatibility & Interactive Gestures

Layout Model:
```text
┌─────────────────┬─────────────────┐
│ Galaxy Orbit    │ Wormhole        │
│                 │                 │
│ FPS: 60         │ FPS: 58         │
│ Particles: 220  │ Particles: 340  │
│ Physics: Yes    │ Physics: Yes    │
└─────────────────┴─────────────────┘
```

2. CORE DELIVERABLES
--------------------------------------------------------------------------------
1. Comparison Laboratory Domain Models
   - Location: lib/src/studio_v2/comparison/studio_comparison_models.dart
   - Components:
     * LoaderComparisonCandidate (loaderId, displayName, fps, particleCount, physics, shaders, renderPassMs, features)
     * LoaderComparisonSession (primary, secondary, deltas, comparedAt timestamp)

2. Studio Comparison Laboratory Engine
   - Location: lib/src/studio_v2/comparison/studio_comparison_engine.dart
   - Capabilities:
     * Maintains primary and secondary evaluation candidate profiles.
     * `setPrimaryCandidate()` & `setSecondaryCandidate()`.
     * `createComparisonSession()` computing delta matrices across FPS, particle load, and raster duration.

     * ASCII Dual-Viewport Comparison Wireframe (matching Phase 10.14 mockup).

     * Structured JSON comparison session schema.
