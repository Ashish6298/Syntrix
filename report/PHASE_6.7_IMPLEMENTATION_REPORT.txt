PHASE 6.7 OBJECTIVE
-------------------
  Implement Phase 6.7 — Publishing Assistant for Flutter Package Studio, turning every capability built across Milestones 5 and 6 into a single, controlled, auditable execution pipeline.
  Create a `ReleasePublishingAssistant` module under `flutter_package_studio_core` that orchestrates the full 11-stage sequence: Validate → Version → Changelog → Build → Manifest → Security Audit → Certification → Git Tag → GitHub Release → Package Publish → Verify.
  Enforce two non-negotiable constraints: no stage ever runs without explicit authorization (`PublishingAuthorization`), and no failure is ever silently absorbed.

================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. PUBLISHING ASSISTANT SUBSYSTEM (`src/release/assistant/`)
   - PublishingAuthorization: Opaque authorization model capturing caller identity (`authorizedBy`), boolean confirmation (`isAuthorized`), and timestamp.
   - StageStatus & StageRecord: Append-only structured execution record tracking stage start, status (pending, inProgress, success, failed, skipped, rolledBack, manualInterventionRequired), details, evidence, and rollbackability.
   - PublishingAssistantOptions & PublishingExecutionResult: Domain models representing execution options, summary, structured stage logs, and formatted Markdown report.
   - ReleasePublishingAssistant: Master orchestrator executing the 11 pipeline stages, enforcing dry run pre-flight gating, critical failure stopping, duplicate release prevention, recovery, and step-by-step rollback.

2. EXCEPTION HIERARCHY EXTENSION
   - Added ReleasePublishingAssistantException extending PackageStudioException in `exceptions.dart`.

3. CLI INTEGRATION (`fps template assistant <template-id>`)
   - Added `fps template assistant <template-id>` subcommand under TemplateCatalogCommand.
   - Supports `--current`, `--target-version`, `--channel`, `--authorize`, `--draft`, `--output`, `--write`, and `--json`.
