1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.4 introduces the Visual Configuration Inspector for Studio v2,
allowing developers to modify all supported loader parameters via dedicated
visual controls without manually writing boilerplate configuration code.

Supported Property Categories & Control Types:
1. Animation (Speed, Intensity, Scale) -> Sliders with step bounds
2. Particles (Count, Size, Opacity) -> Sliders & numeric Steppers
3. Physics (Gravity, Velocity) -> Gravitational & velocity Sliders
4. Dimensions & Layout (Width, Height) -> Pixel Steppers
5. Themes & Colors (Theme ID) -> Dropdown selector of verified themes
6. Shaders & GPU Passes (Shaders Enabled) -> Toggle switches
7. Interactive Gestures (Interactive Mode) -> Toggle switches

Critical Architecture Rules Maintained:
* Exposes only configuration supported safely by package runtime architecture.
* Zero modification to underlying core rendering or calculation algorithms.
* Immediate two-way synchronization with StudioV2Controller and StudioWorkspaceEngine.

2. CORE DELIVERABLES
--------------------------------------------------------------------------------
1. Visual Inspector Domain Models & Schema
   - Location: lib/src/studio_v2/inspector/studio_inspector_models.dart
   - Components:
     * InspectorControlType (slider, stepper, toggleSwitch, colorPicker, dropdownSelect, textInput)
     * InspectorPropertyCategory (7 categories)
     * InspectorPropertyDefinition (keys, labels, bounds, default values)
     * VisualInspectorSchema (`standardPackageSchema()` predefined matrix)

2. Studio Inspector Engine
   - Location: lib/src/studio_v2/inspector/studio_inspector_engine.dart
   - Capabilities:
     * `getPropertyValue()`: retrieves live parameter values dynamically from workspace state.
     * `setPropertyValue()`: mutates specific parameters via controller updates with type coercion.
     * `resetAllProperties()`: resets active configuration back to initial defaults.

3. Studio Inspector Multi-Format Renderer

     * Structured JSON schema export.
