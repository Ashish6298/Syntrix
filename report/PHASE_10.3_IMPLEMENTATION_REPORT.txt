1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.3 creates a professional loader exploration, discovery, filtering,
and comparison laboratory system for Studio v2.

Capabilities Implemented:
* Complete Loader Metadata Schema:
  - Name, Description, Category, Complexity
  - Particles flag, Physics flag, Shader flag, Interactive flag
  - Supported Themes & Feature capabilities
* Multi-Criteria Search & Filtering:
  - Keyword search across name, ID, and description
  - Category filters (Cosmic, Geometric, Fluid, Minimal, Quantum, Retro, Organic)
  - Complexity filters (Lightweight, Standard, Advanced, HighPerformance)
  - Capability flags (Particles, Physics, Shaders, Interactivity)
  - Favorites filter
* Side-by-Side Comparison Engine:
  - Generates comparative capability matrices and shared theme intersections
* Application & Workspace Sync:
  - `selectAndApplyLoader()` directly syncs theme and shader parameters with the active Studio workspace.
