1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.5 implements the Live Preview Engine for Studio v2, enabling real-time
visual feedback as developers interact with Inspector controls.

Architecture Flow Established:
```text
Inspector
    ↓
Configuration State
    ↓
Studio Controller
    ↓
Loader Configuration
    ↓
Existing Rendering Engine
    ↓
Live Preview
```

Key Capabilities Delivered:
* Real-Time Reactive State Updates: Controller listeners trigger instant viewport refresh.
* Playback State Lifecycle Controls: Pause, Resume, Restart Animation, and Reset.
* Viewport Display Modes: Embedded, Fullscreen, Side-by-Side, Isolated Canvas.
* Telemetry Engine: Real-time framerate calculation, frame duration in milliseconds,
  raster duration, min/max frame time bounds, and dropped frame detection.
* Minimal Overhead Invariant: Engine adds zero unnecessary rendering burden to normal package runtime.

2. CORE DELIVERABLES
--------------------------------------------------------------------------------
1. Live Preview Domain Models & Telemetry Descriptors
   - Location: lib/src/studio_v2/preview/studio_preview_models.dart
   - Components:
     * LivePreviewPlaybackState (playing, paused, restarting, stopped)
     * PreviewViewportMode (embedded, fullscreen, sideBySide, isolatedCanvas)
     * FrameTimingSample (frame number, durations ms, particle load, timestamp)
     * LivePreviewMetrics (current FPS, average FPS, frame times, dropped frames)
     * LivePreviewSessionState (full session snapshot model)

2. Studio Live Preview Engine
   - Location: lib/src/studio_v2/preview/studio_preview_engine.dart
   - Capabilities:
     * Listens reactively to StudioV2Controller configuration events.
     * `pause()`, `resume()`, `restartAnimation()`, `resetConfiguration()`.
     * `setViewportMode()` for fullscreen / layout toggling.
     * `recordFrameTiming()` with rolling 60-frame telemetry window and dynamic FPS calculation.

3. Studio Preview Multi-Format Renderer
   - Location: lib/src/studio_v2/preview/studio_preview_renderer.dart
   - Formats:
     * ASCII Live Preview Viewport (reflecting active parameters, telemetry, and canvas simulation).
     * Markdown Telemetry & Performance Sheet.
     * Structured JSON session state export.

4. Barrel Export & Monorepo Integration
   - Exported through: lib/src/studio_v2/studio_v2.dart & lib/flutter_package_studio_core.dart
