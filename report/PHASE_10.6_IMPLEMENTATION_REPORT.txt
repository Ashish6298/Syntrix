1. OBJECTIVES & ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
Phase 10.6 introduces the dedicated Theme & Visual System Studio for Studio v2,
allowing developers to browse, customize, duplicate, compare, and generate
code for the complete theme system.

Theme Browser Capabilities:
* Pre-configured Package Themes:
  1. Deep Space (Abyssal midnight dark, indigo & violet glow)
  2. Milky Way (Spiral galaxy, cyan starlight & opalescent white)
  3. Nebula Storm (Magenta storm, cyan ionization & electric glow)
  4. Quantum Void (Obsidian void, neon emerald quantum highlights)
  5. Solar Flare (Coronal plasma, crimson, fiery amber & gold)
  6. Cyber Galaxy (Synthwave neon cyan, hot pink & dark blue)
  7. Aurora Cosmos (Geomagnetic aurora teal & lavender ribbons)
* Multi-vector Palette Descriptors:
  - Role-based colors (background, primary, accent, glow, particle)
  - Default particle size & opacity characteristics
  - Supported loader bindings
* Operations Supported:
  - `applyTheme()`: directly updates active workspace configuration
  - `duplicateTheme()`: clones existing presets into custom themes
  - `compareThemes()`: generates side-by-side palette comparisons
  - `generateThemeCode()`: produces compile-ready Dart theme classes

Compatibility Guarantee:
* Core theme classes, colors, and runtime behavior remain 100% untouched.
