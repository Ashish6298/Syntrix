  Build a production-grade, deterministic, extensible, secure, and testable

================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. TEMPLATE CERTIFICATION SUBSYSTEM (`src/template/certification/`)
   - TemplateCertificationStatus: Evaluated status states (`certified`,
     `conditionallyCertified`, `failed`, `notCertified`).
   - TemplateCertificationLevel: Tier levels (`basic`, `standard`, `strict`, `release`).
   - TemplateCertificationProfile: Strictness policy profiles (`basic`, `standard`,
     `strict`, `release`). Under release profile, warnings are promoted to errors.
   - TemplateCertificationEvidence: Redacted key-value evidence pairs attached to findings.
   - TemplateCertificationFinding: Finding model capturing rule ID, category,
     severity (`error`, `warning`, `info`), message, file path, remediation guidance,
     and evidence.
   - TemplateCertificationRequest: Encapsulates template targets (raw or resolved),
     profile settings, context, composition plan, customization plan, and hook report.
   - TemplateCertificationReport: Aggregated report containing findings, status, level,
     pass/fail flags, error/warning/info counts, `isGenerationEligible` gate, and JSON export.
   - TemplateCertificationRule & TemplateCertificationRuleRegistry: Extensible rule contract
     and registry. Built-in rules include:
       * ManifestIdentityCertificationRule (CERT-001)
       * DependencySafetyCertificationRule (CERT-002)
       * CompatibilityCertificationRule (CERT-003)
       * PathSecurityCertificationRule (CERT-004)
       * CompositionProvenanceCertificationRule (CERT-005)
       * CustomizationCertificationRule (CERT-006)
       * HookSecurityCertificationRule (CERT-007)
       * QualityEngineAggregationRule (CERT-008)
   - TemplateCertificationEngine: Evaluates certification rules against a request,
     applies release severity promotion, sorts findings deterministically, and builds
     the certification report.
   - TemplateCertificationService: Higher-level orchestrator providing clean certification
     gates (`isGenerationEligible`) for project generation pipelines.

2. EXCEPTION HIERARCHY EXTENSION
   - Added `TemplateCertificationException` and `TemplateCertificationValidationException`
     extending `TemplateException` in `exceptions.dart`.

3. CLI INTEGRATION (`fps template certify`)
   - Added `fps template certify <template-id>` subcommand under TemplateCatalogCommand.
   - Supports `--version`, `--profile`, and `--json` flags.
