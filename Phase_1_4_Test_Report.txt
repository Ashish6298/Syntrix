--------------------------------------------------------------------------------
2. ARCHITECTURE & REPOSITORY GENERATOR CAPABILITIES
--------------------------------------------------------------------------------
- RepositoryOptions & Extensible Preset Profiles:
  Immutable domain model supporting repository name, author, email, license,
  preset profiles (`minimal`, `standard`, `open_source`, `maintainer`), branch name,
  and configurable file generation flags.
- License Provider & Legal Asset Generator:
  Dedicated license resolver supporting `MIT`, `Apache-2.0`, `BSD-3-Clause`, `GPL-3.0`,
  and `none` with variable substitution (`author`, `year`).
- File Builders:
  - `GitignoreBuilder`: Tailored ignore patterns for Flutter, Dart, IDEs, and OS files.
  - `CiWorkflowBuilder`: Deterministic GitHub Actions CI workflow (`.github/workflows/ci.yml`).
  - `RepositoryFileGenerator`: Templated documentation generator utilizing core `TemplateContext`.
- Deterministic In-Memory Planning:
  `RepositoryGenerationPlan` & `RepositoryAction` provide a non-mutating preview
  plan suitable for `--dry-run` simulation mode.
- Git Service Abstraction:
  `GitService` and `SystemGitService` abstract local `git init` and default branch
  renaming (`git branch -M main`) using safe process execution. Mockable in unit tests.
- Security & Path Sanitization:
  All repository file paths resolve strictly within the target project root via `_sanitizePath`.
  Rejects absolute paths and `../` path traversal attempts.
