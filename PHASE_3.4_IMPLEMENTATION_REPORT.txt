================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. MERMAID DIAGRAM SUBSYSTEM (`src/documentation/mermaid/`)
   - MermaidType: Supported diagram types (`flowchartTD`, `flowchartLR`, `sequenceDiagram`).
   - MermaidNode & MermaidEdge: Domain models for nodes and connections with deterministic sorting.
   - MermaidDiagramOptions, MermaidDiagramPlan & MermaidDiagramResult: Immutable preview plan
     and rendered `.mmd` string output models with JSON export.
   - MermaidValidator: Validation engine checking node ID syntax (`[a-zA-Z0-9_]+`), duplicate
     node detection, and missing edge target validation.
   - MermaidDiagramGenerator: Core generator rendering clean, deterministic `.mmd` string source.

2. EXCEPTION HIERARCHY EXTENSION
   - Added MermaidGenerationException extending PackageStudioException in `exceptions.dart`.

3. CLI INTEGRATION (`fps template mermaid`)
   - Added `fps template mermaid` subcommand under TemplateCatalogCommand.
   - Supports `--type` (`flowchart`, `sequence`), `--output`, `--write`, and `--json`.
