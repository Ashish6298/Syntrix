PHASE 2.10 OBJECTIVE
--------------------
  Introduce a production-grade, deterministic, isolated, extensible, secure, and
  testable Template Testing Framework under `lib/src/template/testing/` that automatically
  verifies raw, resolved, composed, customized, and hook-processed templates before
  certification, registration, publication, or release.

================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. TEMPLATE TESTING FRAMEWORK SUBSYSTEM (`src/template/testing/`)
   - TemplateTestStatus: Test execution states (`passed`, `failed`, `skipped`, `error`).
   - TemplateTestProfile: Profiles (`basic`, `standard`, `strict`, `release`).
   - TemplateTestAssertion & TemplateTestAssertionResult: Expectation assertions for
     findings, paths, variables, metadata, compatibility, quality, certification, and secrets.
   - TemplateTestFinding: Finding model capturing test ID, category, severity (`error`,
     `warning`, `info`), message, file path, and remediation advice.
   - TemplateTestResult: Execution outcome for a single test case.
   - TemplateTestRequest: Encapsulates template target (raw or resolved), profile settings,
     context, and dry-run flag.
   - TemplateTestReport: Aggregated report containing test results, findings, counts
     (`passedCount`, `failedCount`, `skippedCount`), `isTested`, `isEligibleForCertification`,
     and JSON export.
   - TemplateTestFixture: Helper factory constructing isolated in-memory valid, invalid,
     incompatible, and path-security violation template fixtures.
   - TemplateTest & TemplateTestRegistry: Extensible test contract and registry.
     Built-in tests include:
       * ManifestSchemaTest (TEST-001)
       * SemverValidityTest (TEST-002)
       * SdkCompatibilityTest (TEST-003)
       * PathSecurityTest (TEST-004)
       * QualityEngineVerificationTest (TEST-005)
       * CertificationEligibilityTest (TEST-006)
   - TemplateTestHarness: In-memory isolated test harness managing sandboxed file systems,
     logger isolation, and mock SDK environments.
   - TemplateTestEngine: Orchestrates execution of tests, enforces profile rules, sorts
     findings deterministically, and builds the test report.
   - TemplateTestingService: Higher-level service providing testing workflows and certification
     eligibility decisions.

2. EXCEPTION HIERARCHY EXTENSION
   - Added `TemplateTestingException`, `TemplateTestConfigurationException`,
     `TemplateTestExecutionException`, and `TemplateTestAssertionException` extending
     `TemplateException` in `exceptions.dart`.

3. CLI INTEGRATION (`fps template test`)
   - Added `fps template test <template-id>` subcommand under TemplateCatalogCommand.
   - Supports `--version`, `--profile`, `--dry-run`, and `--json` flags.
