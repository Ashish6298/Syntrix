# flutter_package_studio_core

Core architectural library and deterministic engine for **Syntrix** (*Flutter Package Studio*).

## Features

* **Composable Blueprint Engine**: Strict YAML schema validation, token transforms, and atomic dry-run previews.
* **Deterministic Audit Gates**: Multi-profile code and repository quality analysis.
* **AI Command Center Subsystems**: AST-aware reviews, root-cause failure diagnosis, and session memory.
* **Hermetic Testing & Release Hardening**: Pre-publish certification and regression baselines.

## Usage

Add this package to your `pubspec.yaml`:

```yaml
dependencies:
  flutter_package_studio_core: ^1.0.0
```
