# flutter_package_studio_cli

The native executable command-line interface for **Syntrix** (*Flutter Package Studio*).

## Installation

Activate globally via pub:

```bash
dart pub global activate flutter_package_studio_cli
```

Verify installation:

```bash
syntrix --version
# or
fps --version
```

## Quickstart

Launch the interactive package wizard:

```bash
syntrix create my_package
```

Run automated package health audits:

```bash
syntrix --audit
```

## Documentation

For full command documentation and capabilities, see the [Syntrix Documentation](https://github.com/Ashish6298/Syntrix).
