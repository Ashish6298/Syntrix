PHASE 3.7 OBJECTIVE

  Introduce a production-grade, deterministic, plan-first GIF Pipeline subsystem
  capable of defining, discovering, validating, organizing, and managing GIF animations
  and manifests for generated Flutter packages and their documentation.

================================================================================
  SUMMARY OF IMPLEMENTATION
================================================================================

1. GIF PIPELINE SUBSYSTEM (`src/documentation/gifs/`)
   - GifCategory: Supported animation categories (`demo`, `feature`, `workflow`, `onboarding`, `custom`).
   - GifItem: Domain model representing GIF animation metadata (`id`, `title`, `path`, `category`, `description`).
   - GifOptions, GifPlan & GifResult: Immutable preview plan and rendered Markdown gallery output models with JSON export.
   - GifValidator: Validation engine checking animation formats (`.gif`, `.webp`), relative path requirements,
     path traversal (`..`) prevention, and duplicate ID prevention.
   - GifManager: Core manager service rendering clean, deterministic Markdown GIF galleries.

2. EXCEPTION HIERARCHY EXTENSION
   - Added GifPipelineException extending PackageStudioException in `exceptions.dart`.

3. CLI INTEGRATION (`fps template gifs <template-id>`)
   - Added `fps template gifs <template-id>` subcommand under TemplateCatalogCommand.
   - Supports `--version`, `--category` (`demo`, `feature`, etc.), `--output`, `--write`, and `--json`.
